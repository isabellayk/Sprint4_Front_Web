📸 UltraFrame - Registro Acadêmico Inteligente

O UltraFrame é uma solução criada para transformar a câmera do celular em uma assistente de estudos, eliminando ruídos, borrões e desorganizações de registros acadêmicos (como fotos de lousas e cadernos).

🛠️ Tecnologias Utilizadas

React: Biblioteca principal para construção da interface de usuário.

Vite: Ferramenta de build rápida e ambiente de desenvolvimento local.

Tailwind CSS: Framework utilitário para estilização e suporte à responsividade.

EmailJS: API para envio de e-mails diretamente pelo front-end no formulário de contato.

JavaScript (ES6+) & HTML5: Estruturação e lógica da aplicação.

🚀 Como Instalar as Dependências

Antes de iniciar, certifique-se de ter o Node.js instalado em sua máquina.

Clone o repositório para o seu ambiente local:

git clone https://github.com/isabellayk/Sprint4_Front_Web.git


Acesse a pasta do projeto:

cd Sprint4_Front_Web


Instale todas as dependências necessárias:

npm install


💻 Como Executar o Projeto

Execute o servidor de desenvolvimento:

npm run dev


Abra o navegador no endereço exibido no terminal.

🖥️ Servidores Back-end

Nesta versão do projeto não há servidor Back-end dedicado. Todas as integrações (como o disparo de e-mails do formulário de contato) foram realizadas via API Serverless/Front-end utilizando o EmailJS.

🔑 Usuários e Senhas para Testes

A aplicação é uma Landing Page institucional e não possui sistema de autenticação/login que exija credenciais de acesso.

🤖 Uso de Inteligência Artificial no Projeto

A Inteligência Artificial foi utilizada como ferramenta de suporte ao desenvolvimento, especificamente na refatoração e migração das regras de estilização de CSS tradicional (incluindo media queries de responsividade) para utilitários do Tailwind CSS. A IA auxiliou no ajuste de classes para garantir o alinhamento correto dos componentes e solucionar conflitos de renderização de layouts e inputs em telas móveis e desktop.
